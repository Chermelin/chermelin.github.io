# chermelin.github.io
This repository hosts the source for my GitHub Pages site as well as a sample
React Native project called **Loopi**.

## Loopi Mobile App

The `loopi-app` directory contains a minimal React Native/Expo project that
demonstrates the main screens and navigation for the Loopi mobile app. It uses
dummy data and stubs for all backend interactions.

### Running the app

1. Install [Expo CLI](https://docs.expo.dev/) and Node dependencies.
2. In the `loopi-app` folder run `npm install` and then `npm start`.
3. Use the Expo app on your device or an emulator to view the project.

> **Note**: the code is intentionally lightweight and omits real auth, Spotify
integration, and offline sync logic. These areas are marked with TODO comments
for future development.
